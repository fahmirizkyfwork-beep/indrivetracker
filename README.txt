Perubahan:
- Angka utama di bagian atas Dashboard sekarang adalah PENDAPATAN BERSIH HARI INI.

CARA MEMPERBARUI:
1. Ekstrak ZIP ini.
2. Buka repository GitHub.
3. Add file > Upload files.
4. Pilih seluruh file hasil ekstrak, termasuk index.html dan sw.js.
5. Commit changes.
6. Tunggu GitHub Pages selesai menerbitkan.
7. Buka ulang aplikasi. Jika masih versi lama, tutup aplikasi lalu bersihkan cache situs / refresh.

Catatan: data tersimpan lokal tidak dihapus oleh pembaruan ini.
